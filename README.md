## 💫 About Me

I'm a Computer Science undergraduate focused on building
**real-world software products from idea to implementation.**

My approach combines:

- Product thinking
- Full-stack engineering
- Backend architecture
- API design
- Database design
- Real-time systems
- Performance and reliability

I don't want to build applications just to demonstrate a
technology.

I prefer to start with:

**Problem → Users → Requirements → System Design → Implementation → Trade-offs**

Then build the simplest system that actually solves the problem.


## 🧠 Engineering Mindset

### 01 — Start With The Problem

Before writing code, I ask:

- What problem are we solving?
- Who actually has this problem?
- What happens if we don't solve it?
- What is the simplest useful version?
- What should happen when things fail?

### 02 — Design Before Implementation

I think about:

- Data flow
- API boundaries
- Database models
- Authentication
- Validation
- Error handling
- Scalability
- Observability

### 03 — Build For Real Usage

I care about what happens beyond the happy path:

- Invalid requests
- Duplicate operations
- Authentication failures
- Database failures
- Race conditions
- Slow APIs
- Real-time updates
- Growing traffic

### 04 — Understand Trade-offs

There is rarely one perfect technology.

I try to understand:

**Why this technology?**

**Why not another one?**

**What problem does it solve?**

**What does it cost?**


## 🚀 What I'm Building

### Trade X — Real-Time Trading Platform

A full-stack trading platform designed around the workflows
of a modern brokerage product.

**Engineering focus:**

- Real-time market price updates
- WebSocket communication
- Candlestick charting
- Order workflows
- Portfolio management
- Holdings and positions
- Authentication & authorization
- Redis integration
- REST API architecture
- MongoDB persistence

**Product thinking:**

> How should a trading platform behave when prices change,
> orders are submitted, data becomes stale, or services fail?

---

### Job Discovery Platform

A job discovery system designed to reduce the repetitive work
of searching across multiple job platforms.

**Product problem:**

Searching for the same roles across different websites
creates repetitive manual work.

**Engineering focus:**

- Job aggregation
- Keyword-based discovery
- API integration
- Filtering
- Deduplication
- Refresh-based job discovery
