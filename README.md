## 💫 About Me

I'm a Computer Science undergraduate focused on intersection of:

- Full Stack Web Applications
- Real-Time Systems
- REST APIs
- Backend Architectures
- AI-powered Applications

My focus is not just writing code, but understanding the problem behind the software.

I like to think about how users interact with a system, how data flows through it, how APIs communicate, and what happens when things fail.

## 🌱 Currently Learning
